# Airline Sales Analytics

## 📌 Project Overview
This project highlights my **airline sales support expertise** by analyzing competitor fares, quarterly sales trends, demand growth, profitable routes, and customer/channel behavior.  
It complements my Revenue Analytics repo by focusing on **pricing, demand, and sales strategy**.

## 🎯 Objectives
- Compare competitor pricing strategies
- Analyze quarterly sales performance (Q1–Q3)
- Study demand growth by route
- Identify top 5 profitable routes
- Explore discount strategies for low‑traffic routes
- Simulate promo fares in lean season
- Model dynamic fare adjustments
- Benchmark airline sales KPIs against competitors
- Analyze booking channel distribution & customer satisfaction (NPS)

## 📂 Datasets
- Kaggle Flight Price Dataset → Pricing & seasonal fare trends
- Monthly Airline Performance Dataset → Quarterly sales, demand growth, profitability
- GitHub Airline Booking Analysis → Channel mix (Direct vs OTA vs GDS)
- Maven Analytics Passenger Satisfaction → NPS, loyalty, fare sensitivity

## 🛠️ Tools
- SQL Server Express → Sales breakdowns
- Python (Pandas, Plotly, Seaborn) → Fare comparisons & demand analysis
- Power BI → Sales & Pricing dashboard

## 📊 Key Analyses & KPIs

| **Analysis Area**   | **Sample KPI / Metric**        | **Formula / Method** |
|----------------------|--------------------------------|-----------------------|
| Pricing Analysis     | Competitor Fare Comparison    | Avg fare by airline/route |
| Sales Trends         | Quarterly Sales (Q1–Q3)       | Revenue grouped by quarter |
| Demand Analysis      | Demand Growth by Route        | Passengers ÷ Seats (trend) |
| Route Profitability  | Top 5 Profitable Routes       | Fare × Load Factor × Distance |
| Discount Strategy    | Low‑Traffic Routes            | LF < threshold, simulate discount impact |
| Promo Fares          | Lean Season Pricing           | Seasonal demand vs fare reduction |
| Dynamic Pricing      | Fare Adjustments              | Demand curve modeling |
| Customer Channels    | Booking Mix                   | Direct vs OTA vs GDS share |
| Customer Insights    | NPS & Loyalty                 | Satisfaction vs pricing correlation |

## 📈 Deliverables
- SQL scripts for sales analysis
- Jupyter notebooks for pricing & demand trends
- Power BI dashboard: **Sales & Pricing Insights**
- Scenario Simulation Dashboard: “What if” analysis (fare cuts, new routes, channel shifts)
